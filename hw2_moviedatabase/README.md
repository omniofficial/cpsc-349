# Movie Explorer Project

Simple frontend application build using HTML, CSS, and JS for CPSC 349. This will use the TMDB API and display movies in a grid.

## File names (IMPORTANT, RENAME IF DIFFERENT FROM THESE NAMES)

index.html - Main HTML file
script.js - JS handles API request, rendering, search, and sorting
styles.css - Basic styling for grid / movie cards

## Features

- Displays popular movies with images
- Next / Previous pages
- Search by movie title
- Sort by release date or rating
